\section{Target-Speaker Recognition}
\label{sec:tsasr}

\subsection{Setup}

We evaluate target-speaker recognition (TS-ASR) on three test sets:

\begin{itemize}
  \item \textbf{Internal hot+TS test set (\texttt{ts\_hw\_test}).}
        % TODO: describe the construction process: source corpus, mixing

        Mandarin two-speaker mixtures with target-speaker reference and
        a small in-prompt hotword list.
  \item \textbf{LibriMix~2 (Libri2Mix).} The standard public
        two-speaker mixture benchmark derived from
        LibriSpeech~\cite{cosentino2020librimix}.
  \item \textbf{LibriMix~3 (Libri3Mix).} The three-speaker variant of
        LibriMix.
\end{itemize}

For all three sets the prompt carries either a short reference utterance
of the target speaker or a speaker identifier

\subsection{Analysis}

\paragraph{Strong on the in-domain set.}
$14.29$\% MER on the internal hot+TS set indicates that when the model
sees mixtures whose acoustic conditions and reference-utterance pipeline
match the training distribution, the prompt-based target-speaker path
works as intended.

\paragraph{Substantial gap on LibriMix.}
LibriMix numbers are much weaker -- $65.83$\% WER on Libri2Mix and
$87.06$\% on Libri3Mix. We have not yet diagnosed the root cause; the
hypotheses we plan to test are
% TODO: replace with the conclusion of the diagnostic effort tracked in
% the project plan (see refs/docs/plan.md).
\begin{enumerate}
  \item Mismatch in reference-utterance length distribution between
        training and LibriMix evaluation;
  \item LibriMix uses LibriSpeech speakers / read speech that the
        model's TS path saw little of during Stage~3;
  \item Insufficient overlap-energy diversity in the training mixtures;
  \item Prompt-template formatting differences (e.g. how the reference
        utterance boundary is signalled).
\end{enumerate}
We treat this gap as a known issue and call it out explicitly in
Section~\ref{sec:limitations}.
