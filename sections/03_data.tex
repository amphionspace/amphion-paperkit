\subsection{Cleaning Pipeline}
% TODO: replace TODOs below with the actual configuration once the data team confirms (VAD model + threshold, langID model, ASR confidence filter and threshold, dedup strategy, PII scrubbing).

We apply a four-stage cleaning pipeline:

\begin{enumerate}
  \item \textbf{VAD.} Voice activity detection with
        % TODO: model name (e.g. Silero VAD vX) + threshold
        a model-based VAD; segments shorter than 1\,s and longer than
        30\,s are dropped.
  \item \textbf{Language identification.} A multilingual LangID model
        % TODO: model name + threshold
        labels each utterance; mismatched labels relative to the source
        manifest are filtered.
  \item \textbf{ASR-based confidence filter.} A reference ASR system
        % TODO: which model used as filter
        scores each utterance; we drop utterances below a CER /
        confidence threshold.
  \item \textbf{Deduplication.} Utterance-level near-duplicate removal
        via MinHash on the transcripts, plus document-level dedup
        across (source, transcript) pairs.
\end{enumerate}

sampling so that low-resource languages and the code-switching slice are
not drowned out by the larger Mandarin and English buckets.
