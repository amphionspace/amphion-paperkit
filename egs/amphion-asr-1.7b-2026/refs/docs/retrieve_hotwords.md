# Hotword Retrieval 方法论（用于论文 Method 章节）

> 写作约束：只描述原理与设计动机，不涉及缓存、并行、倒排索引等工程优化。所有打分函数的权重以"经验阈值 + 失败模式驱动"的方式陈述，而非作为最优解。
> 工程实现与 prompt 字段、训练流水线对接细节见 integrations_tasks_and_prompts.md 第 3.2、6.2.2、8.x 节；本文档专注算法原理。

## 1. 问题形式化

输入：音频信号 \(x\) 与全集热词池 \(\mathcal{H}=\{h_1,\dots,h_N\}\)，其中 \(N\) 可达 \(10^3 \sim 10^4\)。

输出：转写 \(\hat{y}\) 逼近真实文本 \(y\)。

目标：在 \(\hat{y}\) 中正确还原 \(y\) 所包含的热词（用 Recall@K、Precision、CER 三类指标共同度量）。

朴素方案 \(\hat{y}=\arg\max P(y \mid x, \mathcal{H})\) 在 \(N\) 大时不可行：

| 失败原因 | 表现 |
| --- | --- |
| 上下文长度溢出 | \(\mathcal{H}\) 序列化后超过 LLM 上下文窗 |
| 注意力稀释 | 无关热词与真实热词在注意力分布上无差异，热词信号被均摊 |
| 幻觉注入 | LLM 在 \(x\) 信息不足时倾向"拼接"无关热词片段，反而劣化 CER |

引入检索算子 \(\mathcal{R}:(x,\mathcal{H})\!\to\!\mathcal{H}^\prime\subset\mathcal{H},\ |\mathcal{H}^\prime|=K\!\ll\!N\)，最终解码改写为：

\[
\hat{y}=\arg\max P\!\left(y \mid x,\, \mathcal{H}^\prime=\mathcal{R}(x,\mathcal{H})\right).
\]

\(K\) 的选取需在两个矛盾之间折中：增大 \(K\) 提升 \(\mathcal{R}\) 的召回 \(\mathrm{Recall}@K\)，同时按比例增加注意力稀释与幻觉风险。\(\mathrm{Recall}@K\) 在"未召回的热词必错"假设下是下游 ASR 热词命中率的近似上界，因此 retrieve 算子必须独立于下游 ASR 单独评估。

## 2. 两阶段 retrieve-then-bias 范式

将检索算子分解为三个子函数：

| 子函数 | 输入 → 输出 | 角色 |
| --- | --- | --- |
| 粗解码 \(g(x)\) | 音频 → 无热词假设 \(\tilde{y}\) | 把 retrieve 决策从"音频空间"投影到"文本空间" |
| 文本检索 \(r(\tilde{y}, \mathcal{H})\) | 文本 + 热词池 → top-K 候选 \(\mathcal{H}^\prime\) | 无参数纯文本相似度算子 |
| 精解码 \(f(x, \mathcal{H}^\prime)\) | 音频 + top-K → 最终转写 \(\hat{y}\) | 与 SFT 阶段的 hotword-aware ASR 同分布 |

关键洞察：把 retrieve 从「直接在音频空间检索热词」（需要额外的音频-文本对齐网络）降维到「在文本空间检索热词」（纯字符串相似度即可）。这一降维有代价（\(\tilde{y}\) 中的 ASR 错误会传播到 \(r\)），也有红利（\(r\) 完全无参数、可解释、零额外训练数据）。

第一性论证：是否需要专用检索模型（如 dual-encoder）？

不需要。理由有三：

1. 物理必然层面，热词 \(h\) 在音频中出现 ⇔ 其拼音/字符序列在最佳音学路径上有对应区段。粗解码 \(\tilde{y}\) 已经把这一对应"显式化"为文本，再做文本-文本相似度等价于在音学最佳路径附近做模糊匹配。
2. 工程约定层面，独立检索模型需要 hotword-utt 对齐标注，本工作的训练数据不提供这一信号。
3. 历史包袱层面，过往依赖独立检索器的方案（如 H-PRM）需要为每个新领域重新训练；无参数算子天然跨领域。

唯一代价是 \(\tilde{y}\) 的错误会传播；下文的多信号融合与全局判别性检查正是为缓解这一传播。

## 3. 多信号相似度评分（核心打分函数）

第一性原理：什么构成"热词 \(h\) 可能在音频 \(x\) 中说出来"的证据？

把证据原子分为四类：

| 原子证据 | 含义 | 性质 |
| --- | --- | --- |
| 字面直接证据 | \(h\) 完整子串出现于 \(\tilde{y}\) | 高精度、低召回 |
| 音学证据 | \(h\) 与 \(\tilde{y}\) 某段子串发音相同/相近 | 中精度、高召回（覆盖同音/近音 ASR 错误） |
| 形态证据 | \(h\) 与 \(\tilde{y}\) 在字符/字符组重叠 | 低精度、高召回（覆盖少量字面错误） |
| 词法证据 | \(h\) 的内容词（去停用词）出现在 \(\tilde{y}\) 的词集合 | 仅在词级切分有意义的字母语言中使用 |

设计要求由信号性质直接推出：

1. 高精度信号给大权重，单独出现即应越过阈值。
2. 召回信号给中等权重，必须与高精度信号叠加才达阈值，避免噪声驱动。
3. 弱信号给小权重，仅作 tie-breaker。
4. 必须存在阈值，使得"只有弱信号支持"的候选被丢弃。

按字符制脚本与词制脚本（以 30% CJK 字符占比为分界）分派到两条不同打分路径。

### 3.1 CJK 路径（中文为代表）

定义四个 \([0,1]\) 上的子分数：

| 子分数 | 形式化 |
| --- | --- |
| 子串命中 \(\mathrm{sub}(h,\tilde{y})\) | \(\mathbf{1}\{h\subseteq\tilde{y}\}\) |
| 拼音滑窗 \(\mathrm{py}(h,\tilde{y})\) | 在 \(\tilde{y}\) 的去声调拼音序列上滑动长度为 \(\lvert h \rvert\) 的窗，与 \(h\) 拼音逐位置匹配，取最大匹配比例 |
| 字符召回 \(\mathrm{ovl}(h,\tilde{y})\) | \(h\) 中字符出现在 \(\tilde{y}\) 字符集中的比例 |
| Bigram Jaccard \(\mathrm{jac}(h,\tilde{y})\) | \(h\) 与 \(\tilde{y}\) 的字符二元组集合的 Jaccard 相似度 |

线性融合：

\[
s_{\text{zh}}(h,\tilde{y}) = 2.0\,\mathrm{sub} + 1.5\,\mathrm{py} + 0.5\,\mathrm{ovl} + 0.3\,\mathrm{jac}.
\]

接受条件：\(s_{\text{zh}} > 1.0\)。

阈值 \(1.0\) 的语义约束：完全依赖两个弱信号的得分上界为 \(0.5+0.3=0.8<1.0\)，因而无任何子串或拼音证据的候选必然被剔除；同时阈值落在两个非弱信号（子串 2.0、拼音满分 1.5）单独激活的可达分数之下，保证有效信号一旦出现即可通过。\(1.0\) 是满足该区间约束的整数选择，并非唯一最优解（如 0.85 同样满足约束），但实测对该区间内取值不敏感。

拼音滑窗的必要性：中文 ASR 最常见的错误模式是同音字替换。例如 ASR 假设输出"富尔马洛夫"而真实热词为"富尔马诺夫"，字面上"诺"被错为"洛"差 1 字，拼音序列 nuò/luò 在去声调下均为 \([\dots, ma, nuo/luo, fu]\)，去声调拼音序列完全相同。此情形下 \(\mathrm{sub}=0\)、\(\mathrm{ovl}=4/5\)、\(\mathrm{jac}<0.5\)，唯有 \(\mathrm{py}=1.0\) 提供了决定性证据。去掉拼音通道后该类失败模式无可挽救。

### 3.2 字母语言路径

定义子分数：

| 子分数 | 含义 |
| --- | --- |
| 子串命中 \(\mathrm{sub}\) | \(h\) 完整子串出现于 \(\tilde{y}\) |
| 内容词重叠 \(\mathrm{wovl}\) | \(h\) 内容词集合（去停用词）在 \(\tilde{y}\) 词集合中的命中比例 |
| 最佳子串相似度 \(\mathrm{subsim}\) | 在 \(\tilde{y}\) 上滑动取与 \(h\) 在插入-删除距离意义下最相似的子串相似度 |
| 最长公共子序列比 \(\mathrm{lcs}\) | \(\lvert\mathrm{LCS}(h,\tilde{y})\rvert / \lvert h \rvert\) |
| 短词惩罚 \(\mathrm{pen}(h)\) | \(\lvert h \rvert\le 3\) 时 0.35，\(\lvert h \rvert\le 4\) 时 0.20，\(\lvert h \rvert\le 5\) 时 0.10，否则 0 |

线性融合：

\[
s_{\text{en}}(h,\tilde{y}) = 3.0\,\mathrm{sub} + 2.0\,\mathrm{wovl} + 1.5\,\mathrm{subsim} + 0.5\,\mathrm{lcs} - \mathrm{pen}(h).
\]

接受规则在排序后再用"多层阈值验证"细化：

1. \(\lvert h \rvert \le 4\)：要求 \(\mathrm{sub}\ge 1.0\) 或 \(\mathrm{wovl}\ge 1.0\)（近-精确匹配），否则一律拒绝。原因：3–4 字符词存在大量假阳性母词（"go" 嵌入 "good"，"AI" 嵌入 "air"），任何模糊匹配都不可靠。
2. \(\lvert h \rvert = 5\) 且 \(\mathrm{wovl}=0\)：把 \(\mathrm{subsim}\)、\(\mathrm{lcs}\) 阈值从默认 0.65 / 0.60 提到 0.75 / 0.70。
3. 多词热词且 \(\mathrm{wovl}<0.01\)：要求 \(\mathrm{subsim}\ge 0.80\) 且 \(\mathrm{lcs}\ge 0.75\)，防止跨词的"巧合公共字符"通过。

全局判别性检查：若 \(\mathrm{top1}/\mathrm{top10}<1.30\)，整批返回空。

这一规则来源于检索领域的"discriminative gap"思想：若得分最高的候选与第 10 名近乎平起平坐，说明评分函数对当前 \(\tilde{y}\) 没有真正"打开"任何信号——所有候选都是平均水平的噪声响应。此情形下宁可空 retrieve（让 LLM 退化到无热词 ASR）也不要 K 个噪声候选；后者会以注入式 hallucination 的形式劣化 CER。

字母语言路径需要此检查而 CJK 路径不需要的根本原因：CJK 路径的拼音通道带有"音节"硬切分，子串和 bigram 在错配时取值天然集中在 0 附近，top1 与 top-K 之间存在自然的尺度差；字母语言路径的字符级模糊匹配（\(\mathrm{subsim}\)、\(\mathrm{lcs}\)）在长候选池中容易给"任意候选"都打出 0.4~0.6 的中等分，需要显式的全局判别约束来识别这种"评分函数集体退化"的局面。

### 3.3 两条路径的统一观点

CJK 路径强调音学通道，字母语言路径强调词法通道。两条路径共享同一基础范式："高精度信号 + 中精度信号 + 弱信号"按精度递减加权，并由阈值过滤。区别仅在于各信号的物理实现：字符制脚本天然按字切分、词制脚本天然按词切分。从形式上可统一写作：

\[
s(h,\tilde{y}) = \sum_{c\in\text{channels}} w_c \cdot \mathrm{sim}_c(h,\tilde{y}) - \mathrm{pen}(h),\quad
\mathcal{H}^\prime = \mathrm{TopK}\!\left\{h : s(h,\tilde{y})>\tau\right\}.
\]

其中 \(\tau\) 与 \(\{w_c\}\) 满足上节的"弱信号上界 \(<\tau<\) 单一非弱信号"约束。

## 4. 训练时的对偶问题：Hard-negative 检索

retrieve 算子是推理阶段的产物。为使训练分布与推理分布对齐，必须在训练阶段复现 retrieve 输出的 distractor 分布。

朴素做法是从池中均匀采 distractor 与真热词混合。这会产生训练-推理 gap：

| 阶段 | distractor 性质 |
| --- | --- |
| 训练（均匀采样） | 与真热词在字面、音学上几乎独立——易区分 |
| 推理（retrieve 输出） | 与真热词共享字符、音节、bigram——难区分 |

模型在易区分分布上训练，自然在难区分分布上崩溃。

解决方案：训练阶段主动注入 hard-negative，每条 prompt 的候选构成

\[
\{\text{real}\}\ \cup\ \{\text{hard-negative}\}\ \cup\ \{\text{random distractor}\},
\]

其中 hard-negative 来源于以下两类近邻：

### 4.1 字符近邻（基于参考文本 \(y\)）

对每个训练样本的参考文本 \(y\)，收集 \(y\) 的字符集合，从全池中找出与该集合有交集的候选热词，按

\[
0.6 \cdot \mathrm{char\_overlap}(h, y) + 0.4 \cdot \mathrm{bigram\_jaccard}(h, y)
\]

打分取 top-K。这一信号与 §3.1 的 \(\mathrm{ovl}\)、\(\mathrm{jac}\) 同源，刻画"字面接近但语义不同"的近邻。

### 4.2 同音/近音近邻（基于真热词 \(r\)）

对每个真热词 \(r\)，定义两类同音邻居：

1. 拼音 exact 邻居：拼音序列与 \(r\) 完全相同的所有热词。语义上对应"同音字"（如"颜妮" 与"严妮"拼音同为 yán-ní）。
2. 单音节编辑邻居：拼音序列与 \(r\) 等长且 Hamming 距离为 1 的所有热词。语义上对应"换一字近音"（如"诸葛紫岐"vs"诸葛紫祁"差末位音节）。

形式化：设 \(\phi(h)\in\Sigma^*\) 是热词 \(h\) 的去声调拼音音节序列，

\[
\mathcal{N}_{\mathrm{exact}}(r) = \{h\in\mathcal{H} : \phi(h)=\phi(r)\},\quad
\mathcal{N}_{\mathrm{edit1}}(r) = \{h\in\mathcal{H} : |\phi(h)|=|\phi(r)|,\ d_H(\phi(h),\phi(r))=1\}.
\]

\(d_H\) 为 Hamming 距离。两类邻居合并去重后即为 \(r\) 的同音 hard-negative。这一定义直接对应"模型最易把 \(r\) 误识为何"的物理直觉：完全同音 → 必须靠拼写或语义线索区分；差 1 音节 → 必须靠声学细节区分。两者都是从音学到拼写的"最后一公里"。

### 4.3 召回不全模拟

训练 prompt 中的真热词以独立概率 \(p_{\text{miss}}\)（默认 0.12）被丢弃，模拟推理时 retrieve 召回不全的极端场景。整段热词行以概率 \(p_{\text{drop}}\)（默认 0.2）整体省略，使模型在 prompt 无热词时仍能正常工作（对应推理 §3.2 的"全局判别性检查"触发后退化到无热词 ASR 的场景）。

## 5. 训练-推理一致性论证

把检索算子 \(\mathcal{R}\)、训练数据增广 \(\mathcal{A}\)、奖励函数 \(\mathcal{J}\) 三者串成闭环：

| 推理阶段事件 | 训练阶段对应增广 |
| --- | --- |
| \(\mathcal{R}\) 返回的 K 个候选中混有字面/音学近邻 | \(\mathcal{A}\) 注入字符 + 同音 hard-negative |
| \(\mathcal{R}\) 召回不全（真热词被遗漏） | \(\mathcal{A}\) 以 \(p_{\text{miss}}\) 独立丢弃真热词 |
| \(\mathcal{R}\) 因判别性不足返回空（无热词模式） | \(\mathcal{A}\) 以 \(p_{\text{drop}}\) 整体省略热词行 |
| \(\mathcal{R}\) 输出候选数 \(K\) 浮动（不同领域池大小不同） | \(\mathcal{A}\) 在 \([1,\min(K_{\max},\lvert\mathcal{H}\rvert)]\) 内均匀采样候选数 |

SFT 阶段通过覆盖整个 retrieve 行为谱训练模型；GRPO 阶段以 hotword_match_accuracy

\[
R_{\text{hw}}(\hat{y}, y; C) = \frac{1}{|C|}\sum_{c\in C}\mathbf{1}\!\left\{\mathbf{1}[c\in\hat{y}] = \mathbf{1}[c\in y]\right\}
\]

作为可验证奖励，把"候选在/不在输出"的二值判别推向边界，弥补 SFT 的边际样本。这一三段对齐使得 retrieve 算子的所有失败模式都在训练时有对应分布覆盖。

## 6. 设计选择的反事实分析

| 设计 | 反事实（不采用该设计的后果） |
| --- | --- |
| 两阶段 retrieve-then-bias | 全量 \(\mathcal{H}\) 进 prompt → 注意力稀释、上下文溢出、幻觉注入；ASR CER 上升 |
| 文本空间检索（而非音频空间） | 需要额外训练 hotword-utt 对齐网络，跨领域泛化差 |
| 拼音通道（CJK） | 同音字替换错误无可挽救；实测 retrieve 召回率从约 50% 跌至 0.7% |
| 多信号加权 + 阈值 | 单信号 retrieve 时 LLM 出现"凑分"幻觉（如把"诸葛紫岐"输出为"朱圣祎若琪紫各庄村"） |
| 全局判别性检查（字母语言） | 无真热词命中时仍返回 K 个噪声 → 注入式 hallucination |
| 短词长度惩罚 | "go"、"AI" 等通用短词高频假阳性 |
| Hard-negative 训练注入 | 训练 distractor 弱、推理 distractor 强 → 模型把近邻热词当真热词输出 |
| 同音 + 单音节编辑邻居 | 仅 exact pinyin 召回不足，漏掉拼音差 1 音节的常见错误 |
| 真热词独立 miss + 整行 drop | 模型把"热词行存在"当作硬触发，推理空 retrieve 时崩溃 |

## 7. 与已有工作的关系

| 方法 | 共同点 | 区别 |
| --- | --- | --- |
| H-PRM（arXiv:2508.18295） | 同样采用 retrieve-then-bias 两阶段范式 | H-PRM 用独立训练的检索网络；本工作用无参数文本相似度，零标注成本、完全可解释 |
| GLCLAP + GRPO（arXiv:2512.21828） | 同样把 retrieve 输出注入 prompt 并以可验证奖励对齐 | 本工作把奖励函数从 contrastive 改为 hotword_match_accuracy，使奖励信号与下游评测指标在形式上完全一致，避免 reward hacking |

"无参数"的精确含义：本工作的检索算子有 \(O(1)\) 个全局常数（4 个权重、1 个阈值、1 个判别比、1 个 miss 概率），且这些常数由"弱信号上界 \(<\) 阈值 \(<\) 单一非弱信号"这类结构性约束推出，跨领域不需要重新拟合。dual-encoder 类检索器有 \(O(10^7)\) 量级的参数，且对每个新领域、新热词分布都必须重新训练或微调。前者的"参数"是设计常数，后者的"参数"是数据驱动权重，两者在统计自由度和迁移成本上相差六个数量级。

## 8. 评估指标

retrieve 算子需要单独评估，不能仅由下游 ASR CER 间接度量：

| 指标 | 含义 |
| --- | --- |
| Recall@K | 真热词被 \(\mathcal{R}\) 召回的比例。在"未召回的热词必错"假设下是 ASR 热词命中的硬上界；该假设近似成立但非严格成立，LLM 语言先验可能在无热词提示时偶然识对 |
| Precision@K | \(\mathcal{R}\) 返回的 K 个候选中真热词占比。直接关联注意力稀释程度 |
| PRR（Positive Rejection Rate） | 在不应触发热词的样本上 \(\mathcal{R}\) 正确返回空的比例 |
| PPR（Pool-induced Precision Rate） | 控制热词池大小变化时 Precision 的稳定性 |

下游 ASR 阶段再报告 CER、Hotword-CER（仅对热词位置计算的 CER）、Hotword Match Accuracy，与 retrieve 阶段指标联合分析才能区分"retrieve 失败"与"ASR 失败"。
